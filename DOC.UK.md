## Ментальна модель

`slug` перетворює довільний Unicode-текст на URL-дружній slug, будь-якою мовою.
Є два способи використання:

1. **Пакетні функції** — `slug.Make`, `slug.Lower`, `slug.Upper`, … використовують
   дефолтну конфігурацію.
2. **Конфігурований `Slug`** — збудуйте його через `New` і функціональні опції
   для власного роздільника, обмеження довжини, мови транслітерації й запасного
   значення для порожнього вводу.

Провідний принцип — що **межі слів ніколи не втрачаються тихо**. Знак пунктуації
розділяє слова, а не склеює їх, а жменька значущих символів стає окремими словами
(`@` → `at`, `&` → `and`). Тож результат лишається читабельним і осмислено
оборотним, а не злитою грудкою.

`Slug` **незмінний після `New`**, тож одне значення можна безпечно ділити між
горутинами.

```go
import "github.com/goloop/slug/v2"
```

## Пакетні функції

```go
func Make(t string) string
func Lower(t string) string
func Upper(t string) string
func IsValid(t string) bool
func MakeUnique(t string, exists func(string) bool) string
func TryMakeUnique(t string, exists func(string) bool, maxTries int) (string, bool)
```

Кожна використовує дефолтну конфігурацію (роздільник `-`, без обмеження довжини,
без мови транслітерації):

```go
slug.Make("Hello World")  // "Hello-World"
slug.Lower("Hello World") // "hello-world"
slug.Upper("Hello World") // "HELLO-WORLD"
```

## Тип Slug і опції

```go
func New(opts ...Option) *Slug

func WithLang(code string) Option
func WithSeparator(sep string) Option // дефолт "-" (DefaultSeparator)
func WithMaxLength(n int) Option
func WithFallback(s string) Option
```

`New` повертає конфігурований, незмінний «виробник», що надає ті самі методи, що
й пакетні функції (`Make`, `Lower`, `Upper`, `IsValid`, `MakeUnique`,
`TryMakeUnique`):

```go
s := slug.New(
    slug.WithLang(lang.UK),    // регіональна транслітерація
    slug.WithSeparator("_"),   // власний роздільник слів (дефолт "-")
    slug.WithMaxLength(60),    // різати на межі слова
    slug.WithFallback("post"), // значення для порожнього результату
)

s.Make("Привіт, світ!") // "Pryvit_svit"
```

| Опція | Ефект |
|-------|-------|
| `WithLang(code)`      | обрати мову транслітерації (див. [нижче](#транслітерація-й-мова)) |
| `WithSeparator(sep)`  | роздільник слів (дефолт `-`) |
| `WithMaxLength(n)`    | обмежити довжину, ріжучи на межі слова, щоб жодне не розбити |
| `WithFallback(s)`     | значення, що повертається, коли slug інакше був би порожнім |

## Правила нормалізації

Нормалізація — це білий список: лише літери й цифри виживають як вміст, усе інше
або стає словом, або роздільником. Правила:

- **Значущі символи стають словами:** `@` → `at`, `&` → `and`, `#` → `sharp`,
  `%` → `pct`.
- **Справжній апостроф між літерами з'єднує їх:** `it's` → `its`.
- **Будь-який інший неалфавітно-цифровий символ — роздільник слів.** Провідні,
  кінцеві й повторювані роздільники згортаються й прибираються.

```go
slug.Make("co-operate")     // "co-operate"
slug.Make("email@site.com") // "email-at-site-com"
slug.Make("R&D 100%")       // "R-and-D-100-pct"
```

Саме цей підхід білого списку гарантує, що роздільники ніколи тихо не зливаються:
пунктуація завжди розбиває слова, а не зникає.

## Транслітерація й мова

Не-ASCII літери транслітеруються в ASCII. `WithLang` обирає регіональні правила;
підпакет `slug/v2/lang` надає коди мов (наприклад `lang.UK`, `lang.EN`):

```go
import "github.com/goloop/slug/v2/lang"

s := slug.New(slug.WithLang(lang.UK))
s.Make("Привіт, світ!") // "Pryvit-svit"
```

Без мови застосовується загальна транслітерація. Правильна мова важлива, коли той
самий символ транслітерується по-різному в різних локалях.

## Регістр

`Make` **зберігає регістр літер вводу**; використовуйте `Lower` чи `Upper`, щоб
нав'язати один:

```go
slug.Make("Hello World")  // "Hello-World"
slug.Lower("Hello World") // "hello-world"
slug.Upper("Hello World") // "HELLO-WORLD"
```

## Унікальність

```go
func (s *Slug) MakeUnique(t string, exists func(string) bool) string
func (s *Slug) TryMakeUnique(t string, exists func(string) bool, maxTries int) (string, bool)
```

`MakeUnique` дописує числовий суфікс, доки ваш предикат `exists` не повідомить, що
кандидат вільний:

```go
s.MakeUnique("hello world", func(candidate string) bool {
    return exists(candidate) // ваш пошук; true, якщо зайнято
}) // "hello-world", "hello-world-2", ...
```

`TryMakeUnique` — обмежений, строгий варіант: пробує щонайбільше `maxTries` разів
і повідомляє, чи знайдено унікальний slug, тож ворожий чи вичерпаний простір імен
не крутитиметься вічно:

```go
if slug, ok := s.TryMakeUnique("hello world", exists, 100); ok {
    use(slug)
}
```

## Валідація

```go
func IsValid(t string) bool
func (s *Slug) IsValid(t string) bool
```

`IsValid` повідомляє, чи рядок уже є канонічним slug для конфігурації — тобто
`Make` повернув би його без змін:

```go
slug.IsValid("hello-world") // true
slug.IsValid("hello world") // false
```

## Рецепти й поради

**Збудуйте один «виробник», використовуйте повторно.** `Slug` незмінний і
потокобезпечний — сконструюйте його раз на старті з вашими опціями й діліться,
а не передавайте опції в кожному місці виклику.

**Обмежуйте цикл унікальності.** Надавайте перевагу `TryMakeUnique` над
`MakeUnique`, коли перевірка `exists` б'є в базу чи великий простір імен, щоб
насичений простір повернув `ok=false`, а не зациклився.

**Дайте порожньому вводу домівку.** Виставте `WithFallback`, щоб текст, який
зводиться до нічого (сама пунктуація, заголовки лише з емодзі), давав стабільний
заповнювач, а не порожній рядок.

**Обирайте мову свідомо.** Використовуйте `WithLang` із правильним кодом `lang`,
коли ваш вміст конкретною мовою; дефолтна загальна транслітерація — безпечний
запасний варіант, а не локале-обізнаний.

**Обрізайте довжину на межі.** `WithMaxLength` ріже на межі слова, тож slug'и
лишаються читабельними й ніколи не закінчуються посеред слова.
